# Astrofy: guia do usuário

Este manual mostra como usar o Astrofy para entender um projeto Astro,
definir uma página por conversa, transformar o conteúdo aprovado em um plano
técnico e acompanhar a implementação.

## Percurso recomendado

1. [Entenda o fluxo completo](00-visao-geral.md).
2. [Instale e execute o setup](01-instalacao-e-setup.md).
3. [Escolha e planeje o tipo de página](02-planejamento-de-pagina.md).
4. [Responda à entrevista de conteúdo](03-entrevista-e-conteudo.md).
5. [Gere o plano de implementação](04-plano-de-implementacao.md).
6. [Implemente e valide](05-execucao-e-validacao.md).
7. [Compare exemplos dos sete tipos de página](06-exemplos-por-tipo-de-pagina.md).
8. [Acompanhe os estados de uma tarefa](07-execucao-retomavel.md).
9. [Retome ou altere um trabalho](08-retomada-e-manutencao.md).
10. [Consulte as soluções para falhas comuns](09-solucao-de-problemas.md).

## Formatos

Os capítulos deste diretório são a fonte canônica. O projeto gera a mesma
edição em PDF e EPUB dentro de `ebook/`. A versão do manual acompanha a versão
do pacote Astrofy.
