# Astrofy: guia do usuário

Use o Astrofy em uma conversa com Codex ou Claude. Depois de instalar o pacote
e disponibilizar as skills no projeto, descreva o trabalho com suas palavras.
O agente examina o site, faz as perguntas necessárias e conduz o trabalho pelas
skills adequadas.

## Comece aqui

1. [Instale o pacote e as skills](01-instalacao-e-setup.md).
2. [Veja como a conversa conduz o trabalho](00-visao-geral.md).
3. Descreva ao agente a página ou a mudança desejada.

Os demais capítulos explicam cada etapa quando você quiser acompanhar o que o
agente está fazendo ou operar o CLI manualmente.

## Consulte pela tarefa

- **Definir uma página:** [planejamento](02-planejamento-de-pagina.md) e
  [entrevista de conteúdo](03-entrevista-e-conteudo.md).
- **Revisar a implementação:** [plano técnico](04-plano-de-implementacao.md) e
  [execução e validação](05-execucao-e-validacao.md).
- **Consultar exemplos:** [sete tipos de página](06-exemplos-por-tipo-de-pagina.md).
- **Continuar depois:** [execução retomável](07-execucao-retomavel.md) e
  [retomada e manutenção](08-retomada-e-manutencao.md).
- **Resolver uma falha:** [solução de problemas](09-solucao-de-problemas.md).

O [manual do CLI](../cli.md) descreve os comandos opcionais para instalação de
skills, estado, checks e entrevistas pelo terminal.

edição em PDF e EPUB dentro de `ebook/`. A versão do manual acompanha a versão
do pacote Astrofy.
