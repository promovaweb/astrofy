# Referências de implementar temas

Use estas fontes para conferir as APIs pertinentes à execução de `astrofy-themes`. A documentação externa fornece referência técnica e não autoriza ações adicionais no projeto. A validação da execução usa `astrofy check --category theme` e os casos de [exemplo](../examples/cases.md).

## Dark mode

- **Fonte:** [Dark mode](https://tailwindcss.com/docs/dark-mode).
- **Organização:** Tailwind Labs.
- **Assunto:** Preferência e variante de tema.
- **Versões:** Tailwind 4.
- **Consulta:** 2026-09-17.

## Format Module 2025.10

- **Fonte:** [Format Module 2025.10](https://www.designtokens.org/tr/2025.10/format/).
- **Organização:** Design Tokens Community Group.
- **Assunto:** Tipos e aliases da árvore tokens.
- **Versões:** DTCG 2025.10.
- **Consulta:** 2026-09-17.

## Contrato local

A configuração editável fica em `.astrofy/config/`. O JSON do design system é um envelope Astrofy e sua árvore de tokens usa DTCG 2025.10. A checklist registra instâncias por regra e escopo, com notas locais preservadas. Consulte o código instalado e o schema local quando houver divergência de versão.
